#Retail Sales Data Analysis (EDA)

This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset to understand sales patterns, profitability, and customer behavior. The dataset was cleaned by checking for missing values, duplicate records, and correcting inconsistent data types.

Several visualizations were created to analyze sales distribution across categories, regions, and customer segments. A correlation heatmap and profit distribution analysis were also performed to understand relationships between different variables.

The analysis helped identify the most profitable products, the least profitable regions, and provided insights that can help improve overall sales performance.
